# 🌦️ Weather Icon Display

A simple and interactive weather display application built using HTML, CSS, and JavaScript.

## About the Project

This project allows users to select different weather conditions from a dropdown menu. Based on their selection, the application displays a matching weather icon, title, description, and background color.

All weather information is stored locally using a JavaScript object. No external API is required.

## Features

- Dropdown for selecting weather conditions
- Matching weather icons and descriptions
- Dynamic background color changes
- Default display before selection
- Simple and responsive user interface

## Technologies Used

- HTML5
- CSS3
- JavaScript

## Project Structure

```text
weather-icon-display/

```

## How to Run

1. Download or clone this repository.
2. Open the project folder.
3. Open `index.html` in your browser.
4. Select a weather condition from the dropdown.
